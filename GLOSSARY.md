# DataProfile

Automated portfolio and statistical visualization generator tailored for data professionals (data analysts, data scientists, machine learning engineers, and researchers).

## Language

**Subject**:
The data professional whose public portfolio, code engineering metrics, and community achievements are portrayed.
_Avoid_: User, Account, Client, Developer

**Source**:
An external platform from which raw professional signals, artifacts, and metrics are collected (such as GitHub, Kaggle, or Hugging Face Hub).
_Avoid_: Integration, Connector, Plugin, Provider

**Panel**:
A standalone SVG visual module representing one specific analytical dimension of the Subject's portfolio (such as language distribution, data stack, or competition performance).
_Avoid_: Widget, Card, Badge, Image

**School**:
An authoritative data-visualization paradigm (such as Tufte, Few, Cairo, or Holmes) that dictates chart geometry, information density, annotation depth, and data-ink ratio across Panels.
_Avoid_: Theme, Skin, Template, Style

**Palette**:
A chromatic and contrast scheme (such as adaptive transparent, light, or dark) applied within a School.
_Avoid_: Theme, Mode, Skin

**Profile Manifest**:
The public, declarative specification identifying the Subject, active Sources, and selected Schools without exposing secret credentials.
_Avoid_: Config file, Settings, Environment file
