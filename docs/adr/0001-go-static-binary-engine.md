# Single static Go binary for multi-source collection and SVG rendering

DataProfile needs to query three upstream Sources concurrently (GitHub, Kaggle, and Hugging Face Hub), strip base64 output bloat from Jupyter notebooks, and render 20 SVG Panels across four visualization Schools inside scheduled GitHub Actions runs. We built the engine in Go 1.23 using only the standard library rather than Python or Node.js. That choice trades native Python data-science bindings for sub-second startup in GitHub Actions Marketplace workflows, native goroutine concurrency across API collectors, and zero external dependency installation in CI.
