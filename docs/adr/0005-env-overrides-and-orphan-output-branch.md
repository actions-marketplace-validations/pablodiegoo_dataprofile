# Environment-overridable manifest and dual-tree orphan output branch

Hardcoding the maintainer's live personal curriculum inside the tracked `profile.yaml` and committing rendered SVGs under `generated/` on `main` forces every bio edit or scheduled metric refresh to pollute the open-source commit history and causes merge conflicts whenever downstream forks sync with upstream. To keep `main` strictly limited to technical engine changes while preserving zero-friction standalone usage for the community, we keep a neutral reference `profile.yaml` on `main`, layer full environment-variable overrides (`.env` and GitHub Actions Variables/Secrets, supporting `[item 1; item 2]` semicolon-delimited bracket lists for multiline fields and arrays) on top of `profile.yaml`, provide a `dataprofile sync` CLI subcommand to push local `.env` overrides to GitHub Actions and trigger regeneration, and remove `generated/` from `main` in favor of publishing two isolated trees on the orphan `output` branch: `output/showcase/` (rendered deterministically with `--demo --no-env` for project documentation) and `output/generated/` (rendered with the Subject's live overrides and credentials).
