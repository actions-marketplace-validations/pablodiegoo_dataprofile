# Hybrid Kaggle collection using headless CDP and optional official REST API

Kaggle's official REST API v1 provides endpoints for datasets, notebooks, and competition submissions, but it does not expose a user's overall tier, category rankings, or medal counts, while plain HTTP requests to public profile pages are blocked by Google reCAPTCHA challenges. Given this limitation, we implemented a hybrid collector that extracts public tiers, ranks, and medals through headless Chrome (speaking Chrome DevTools Protocol to the browser pre-installed on GitHub Actions runners) with zero credentials, and enriches those metrics through the official Kaggle REST API v1 whenever `KAGGLE_KEY` is configured in GitHub Secrets.
