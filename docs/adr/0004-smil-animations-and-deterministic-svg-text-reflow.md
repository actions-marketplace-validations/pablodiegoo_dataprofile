# Native SMIL animations and deterministic Go text reflow for dynamic SVG panels

GitHub's image proxy (Camo) and browser `<img src="...svg">` sandboxes strip `<script>` tags, block external stylesheets and web fonts, and render HTML `<foreignObject>` containers inconsistently across Safari and mobile viewports, while SVG 1.1 lacks native auto-height text containers. To support animated portfolio headers (`header`), elastic multi-line career narratives (`bio` at 440px and `bio-full` at 900px), and full-page composite layouts (`full`), we compute word-wrapping and vertical coordinate offsets deterministically in Go (`internal/render`) using native `<text>`/`<tspan>` elements and pure SVG 1.1 SMIL animations (`<animate>`, `<textPath>`, and `stroke-dasharray`). This guarantees exact `viewBox` height adaptation with zero blank space on short bios, zero overlap on long bios, and smooth continuous animations inside GitHub profile READMEs without external dependencies.
