# Native SMIL animations and deterministic Go text reflow for dynamic SVG panels

GitHub's image proxy (Camo) and browser `<img src="...svg">` sandboxes strip `<script>` tags, block external stylesheets and web fonts, and render HTML `<foreignObject>` containers inconsistently across Safari and mobile viewports, while SVG 1.1 lacks native auto-height text containers or automatic horizontal text fitting. To support animated portfolio headers (`header`), elastic multi-line career narratives (`bio` at 440px and `bio-full` at 900px), analytical cards (`languages`, `stack`, `kaggle`, `impact`, `summary`), and full-page composite layouts (`full`), we compute both vertical word-wrapping/coordinate offsets and horizontal pixel-width budgets deterministically in Go (`internal/render`) using native `<text>`/`<tspan>` elements, adaptive `font-size` scaling down to per-School legibility floors (`estimateTextWidth`, `fitFontSize`, `fitTextAttr`, `fitPairTextAttrs`, `fitHeaderNameRole`), `<clipPath>` quadrant isolation (`440×230`) inside `full.svg`, and pure SVG 1.1 SMIL animations (`<animate>`, `<textPath>`, and `stroke-dasharray`). This guarantees exact `viewBox` height adaptation with zero blank space on short bios, zero horizontal or vertical text overlap or divider collision across `en` and `pt-BR` locales, and smooth continuous animations inside GitHub profile READMEs without external dependencies.
