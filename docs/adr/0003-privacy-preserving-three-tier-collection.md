# Privacy-preserving collection across owned, contributed, and monorepo workspaces

Public GitHub REST endpoints (`/users/{username}/repos`) omit private repositories where data practitioners keep proprietary consultancy, academic, and research code, while naive inclusion of forked repositories inflates language proportions and star counts with third-party codebases. We adopted a three-tier collection boundary across authenticated Sources (GitHub GraphQL/REST, Kaggle API, and Hugging Face Hub): Owned Repositories (public and private, non-fork) undergo deep recursive tree and manifest inspection in memory across all Analytical Workspaces; Contributed Repositories count toward community reach and commit velocity without claiming upstream language bytes or stars; and Passive Forks are excluded by default. All private signals are reduced strictly to aggregate counts and percentages prior to SVG rendering so repository names, file paths, and source code never leak into public outputs.
